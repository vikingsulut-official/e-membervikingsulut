# E-Member Viking Sulut — Dashboard

Repo ini hanya berisi konfigurasi Vercel yang meneruskan (proxy) ke Web App
Google Apps Script sebagai backend & database (Google Sheets).

Tidak ada kode aplikasi di sini — semua logika, tampilan, dan data
dikelola di Google Apps Script (Code.gs, Dashboard.html, Profile.html)
dan Google Sheets.

Untuk mengubah URL tujuan, edit `vercel.json`.
